# 电商智能售后 Agent 开发清单

状态：已开始后端骨架搭建；当前版本和验证结果见 ENVIRONMENT.md。勾选表示已通过该项验收，不只是代码已提交。

## 一、项目范围与约定

- 定位：Java 后端个人简历项目，包含用户端、Agent 和客服管理端。
- 主链路：咨询 → 查询订单 → 校验资格 → 补充信息 → 生成草稿 → 用户确认 → 创建售后单 → 客服处理 → 查询结果。
- 当前业务第一版支持退货退款申请与审核，换货后续实现；一张售后单对应一个订单商品项，支持指定数量。
- 订单使用模拟数据，物流和退款使用可控制成功、失败、超时的模拟接口。
- 模型负责理解、追问、工具选择与解释；身份授权、资格判断、金额计算、数量占用和状态流转由后端代码负责。
- 首版采用模块化单体，暂不引入多 Agent、自动退款决策、真实支付、微服务拆分或通用低代码平台。

建议主状态：
- 退货退款：待审核 → 待寄回 → 待商家收货 → 待退款 → 已完成。
- 换货：待审核 → 待寄回 → 待商家收货 → 待换货发出 → 待用户收货 → 已完成。
- 终止状态：已拒绝、已撤销；具体允许撤销的阶段在编码前形成状态转换表。

验收：普通 API 能完成两类售后流程；重复及并发提交不重复建单、不超占数量、不超额退款。
