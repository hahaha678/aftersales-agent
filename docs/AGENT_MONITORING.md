# Agent 执行监控

客服进入左侧“执行监控”，按状态、会话 ID 和开始时间区间分页查询任务；打开详情查看模型、耗时、Token 记录、工具调用顺序、参数摘要、结果摘要及错误码。页面手动刷新，不触发模型调用或任务重试。

## 启动和联调

1. 重启 local 后端，Flyway 自动执行 V9；无需改动已执行迁移或重建库。
2. 刷新前端，客服账号进入“执行监控”。普通买家不显示入口，直接请求 API 也会被后端拒绝。
3. 买家向智能售后发送“查询 DEMO-1001 的详情”，待完成后刷新监控。查看工具是否被调用、序号、耗时与结果摘要。
4. 若工具返回 INVALID_REQUEST 等业务错误，工具行显示失败；模型正常解释错误时，任务本身可能仍为成功。任务成功只表示完成一次执行，不代表业务办理成功或回答正确。
5. 页面关联到用户提交的人工工单，可从工单读取用户主动共享的上下文。监控不会自动重试失败的工具或退款操作。

## 记录口径

- 复用 agent_run，不额外复制模型输入输出。总耗时从任务创建到结束，包含排队，不包含随后用户确认草稿的时间。运行中展示截至查询时的耗时，不是持续变化的实时计时器。
- RUNNING 且租约到期时，只读展示 EXPIRED；保留 storedStatus，不修改数据库、不恢复循环、不触发付费调用。其耗时截至租约时间，结束时间仍可能为空。
- Token 为现有模型回报的累计记录，不推算人民币费用；0 可能表示没有上报，不能当成零成本。未实现逐次模型请求追踪。
- V9 为 agent_tool_call 增加调用序号、开始时间、参数摘要、结果摘要和错误码。按调用开始顺序展示；完成时间为工具结束后审计写入时间。
- 工具运行结束后在 finally 记录，业务错误返回和预算拒绝也计为失败。第9次预算拒绝会留下记录，但不会执行第9次业务工具。调用次数是尝试次数。
- 如果进程在工具执行中被终止，该未完成调用可能没有日志；目前没有持久化的工具 RUNNING 心跳。任务可能在租约到期后展示 EXPIRED。
- 旧调用记录的新字段为空，页面显示“未记录”，不伪造历史参数、顺序或错误。
- 列表每页默认20条、最多100条；工具次数按当前页任务批量聚合，避免逐条统计查询。

## 参数与访问范围

参数采用白名单：数字 ID、演示订单号、页码、数量、固定原因及范围枚举。问题、描述、额外字段、密码或 Token 均不保存到监控摘要；不采用简单截断原 JSON 的方式。

结果只保留结构类型、条数、字符长度，以及格式合法的资源 ID 和固定状态。原商品、政策、地址等完整内容不写入工具审计。异常只保留固定分类或白名单错误码，不保存异常堆栈、远端响应体或凭据。

客服可以查看执行元数据。原始任务输入和回答仅在当前客服本人创建的任务详情中返回；其他用户的原文不通过监控暴露，也不放宽原会话接口权限。若存在同一会话的人工工单，显示最近20个工单入口，访问工单快照遵循工单权限。工单快照不一定包含本次执行后的回答。

## REST 接口

| 接口 | 用途 |
| --- | --- |
| GET /api/staff/agent-runs | 分页，支持 status、conversationId、from、until、page、size |
| GET /api/staff/agent-runs/{id} | 任务详情与关联工单 |
| GET /api/staff/agent-runs/{id}/tool-calls | 工具执行记录 |

时间参数使用带时区 ISO 8601，前端本地时间转换为 UTC；过滤按任务开始时间，包含 from、不含 until。状态支持 RUNNING、SUCCEEDED、FAILED、CANCELLED、EXPIRED。均为只读接口，有 Swagger 注解。
